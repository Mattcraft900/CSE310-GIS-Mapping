# Rexburg Landmark Map

Find & view info on various landmarks and buildings around BYU-I campus.

## Instructions for Build and Use

Steps to build and/or run the software:

1. With a steady internet connection, go to the URL https://mattcraft900.github.io/CSE310-GIS-Mapping/ in your web browser. (That's it!)

Instructions for using the software:

1. With a steady internet connection, go to the URL https://mattcraft900.github.io/CSE310-GIS-Mapping/ in your web browser. A map will appear of BYU-I campus and the surround area. 
2. Click & drag with the mouse to pan the map around, and use the scroll wheel (or buttons in the top-left of the page) to zoom in/out. 
3. Click on any of the map pins to view a pop-up with more information (Some pins are a few miles away). Light blue pointers indicate local landmarks, and dark blue squares indicate BYU-I campus buildings.
